# LAB07 - Add a filter to an image

Please see problem statement/slides.

## Task 1
Convert the image to a 3D array and change the sky color.

## Task 2
Add filters and effects.

## Try it with your own picture
1. Copy a `.png` or `.jpg` into the project folder (next to `pumpkin.png`)
2. Add its file name to the `args` in `.vscode/launch.json`, e.g. `"pumpkin.png", "me.jpg"`
3. Run `FallFilterApp` and open `me-filtered.png`

iPhone photos are often `.heic`: export them as JPEG first.
No need to upload your own pictures!
